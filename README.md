## 🛠️ Local Development

### 1. Installation
```bash
# Clone the repository
git clone https://github.com/amanshakile-star/my-portfolio.git
cd my-portfolio

# Install frontend dependencies
cd client
npm install
```

### 2. Run Locally
From the root directory or inside `client/`:
```bash
# From root
npm run dev

# Or from client/
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
# From root
npm run build

# Or from client/
npm run build
```

The production output is built to `client/dist/`.

## 🚀 Vercel Deployment

This repository is pre-configured with `vercel.json` and automatic Single-Page Application (SPA) rewrites.

1. Connect your repository `amanshakile-star/my-portfolio` to **Vercel**.
2. Vercel will automatically detect the settings:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm --prefix client run build` (or `npm run build`)
   - **Output Directory**: `client/dist` (or `dist` if Root Directory is set to `client`)
3. Click **Deploy**.

For detailed step-by-step instructions, see [DEPLOYMENT.md](DEPLOYMENT.md).
